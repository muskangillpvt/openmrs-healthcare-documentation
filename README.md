# OpenMRS Healthcare Documentation Portfolio

## Overview

This repository is a technical writing portfolio project focused on documenting workflows and concepts in healthcare software.

The project uses OpenMRS, an open-source electronic medical record platform, as a case study for exploring how technical documentation can help users understand software workflows, troubleshoot common issues, and work with sensitive information responsibly.

## Project Objectives

- Create clear, task-oriented user documentation.
- Explain patient registration workflows.
- Develop troubleshooting guidance for common user difficulties.
- Describe privacy and access-control concepts using reliable sources.
- Maintain traceable sources and clearly document the scope of each guide.

## Documentation

| Document | Purpose |
|---|---|
| Patient Registration Guide | Explain the patient registration workflow for the specified OpenMRS platform and guide version. |
| Troubleshooting Guide | Help users investigate common problems and identify appropriate next steps. |
| Privacy and Access Control | Explain relevant privacy and access-control concepts without making unsupported compliance claims. |
| Glossary | Define key healthcare and software terminology in plain language. |
| Sources and Scope | Record source references, platform distinctions, assumptions, and documentation limitations. |

## Intended Audience

The intended audience includes people learning to use healthcare software, technical writers, and readers interested in software documentation within healthcare environments.

The final audience and user roles will be refined as the documentation is developed.

## Scope and Limitations

This is an independent educational portfolio project. It is not official OpenMRS documentation and is not a substitute for clinical training, organisational procedures, legal advice, or official privacy guidance.

The guides will identify the relevant platform and source material. Features and workflows must be checked against the applicable version before being treated as current instructions.
